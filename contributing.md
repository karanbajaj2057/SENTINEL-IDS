# Contributing to SENTINEL IDS

Thank you for your interest in improving SENTINEL IDS.

## Development Guidelines

- Keep changes focused and easy to review.
- Do not commit secrets, credentials, tokens, or private network data.
- Keep simulated traffic clearly separated from real traffic.
- Document new detection rules and simulated scenarios.
- Add or update tests when detection logic changes.
- Use descriptive commit messages.

## Pull Requests

A pull request should explain:

1. What changed
2. Why it changed
3. How it was tested
4. Any security or behavioral implications
