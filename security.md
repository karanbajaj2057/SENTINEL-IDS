# Security Policy

## Scope

SENTINEL IDS is a defensive simulation project. Security reports relating to the repository, application behavior, dependency vulnerabilities, accidental secret exposure, or unsafe handling of data are welcome.

## Reporting

Please do not publish sensitive security details in a public issue.

Report concerns privately through the contact method configured by the repository owner.

## Responsible Use

Do not use the project to access, monitor, disrupt, or analyze networks without authorization.

Never commit:

- API keys
- Passwords
- Access tokens
- Private certificates
- Credentials
- Real customer or production traffic
- Sensitive logs
